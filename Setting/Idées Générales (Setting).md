## Setting

Médiéval fantastique, avec des [[Mechs]] fonctionnant avec un [[Cœur Magique]]. 

Les Humains se battent pour libérer leur monde, alors que les démons sont là pour utiliser les humains pour créer leurs nouvelles armes.

Les Humains ne peuvent utiliser la magie que pour faire des sorts très simple.

Les démons peuvent utiliser la magie pour utiliser des sort plus puissant.
